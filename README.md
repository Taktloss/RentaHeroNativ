# RentaHeroNativ

Native Neuimplementierung des Adventures „Rent-A-Hero“ (neo Software, 1998/99) für
Linux und Windows. **In Arbeit – derzeit Analysephase.**

Das Repository enthält keine Spieldaten. Zum Spielen wird eine eigene, legale Kopie
des Originals benötigt.
